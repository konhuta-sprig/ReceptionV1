# Reception Investor Demo

A self-contained React demo for the Reception customer journey. It opens on a 10-event monthly portfolio dashboard, then drills into a SoMa client dinner from connected systems and natural-language brief through sourcing, approvals, coordination, booking, attendee ops, day-of execution, ROI, and auditability.

## Run

```bash
/Users/iddhikornhutachinda/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

Then open:

```text
http://localhost:4173
```

React and ReactDOM are vendored in `vendor/`, so the demo runs without `npm` after the initial setup.
